# Hero portrait scale + Anatomy placement

## 1. Smaller hero portrait

In `src/components/hero/Hero.tsx`, the portrait column currently reserves `lg:w-[45%]` with a `620px` tall image that overhangs the section (`lg:-mb-16`) and dominates the right side.

Changes:
- Reduce the portrait frame: max width from `500px` to about `380px` on desktop, height from `620px` to about `500px`, and drop the negative bottom margin so the image sits inside the section.
- Mobile/tablet caps come down proportionally (`300px` → `240px`, `380px` → `300px`), keeping the 4:5 aspect.
- Vertically centre the portrait against the text block instead of bottom-aligning it, so its top and bottom roughly line up with the headline-through-buttons stack.
- Text column widens slightly (`lg:w-[55%]` → `lg:w-[60%]`) to absorb the freed space; nothing else in the hero changes.
