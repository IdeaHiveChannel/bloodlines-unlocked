WHAT TO AVOID

Never include:

 Neon gradients.

 Random floating objects.

 Excessive glass panels.

 Constant particle effects.

 Elastic or bouncing animations.

 Loud color palettes.

 Cartoon medical illustrations.

 Generic smiling stock doctors.

 Agency-style jargon.

 Unverified claims, statistics, or affiliations.
